# Carcassonne Score Tracker

![App Concept](https://img.shields.io/badge/Status-Production_Ready-success?style=flat-square) ![Platform](https://img.shields.io/badge/Platform-iOS_%7C_Android-blue?style=flat-square) ![Tech](https://img.shields.io/badge/Framework-React_Native_%7C_Expo-black?style=flat-square)

A sleek, responsive, and beautifully animated score-tracking utility for the beloved tile-laying board game, Carcassonne. Designed to replace paper and pencil with a fast, intuitive digital companion for your game nights.

## 🌟 Features

*   **Real-time Score Tracking**: Tap to instantly adjust scores for knights, monks, and farmers.
*   **Up to 9 Players**: Seamlessly handles standard games (up to 6 players) and expanded games (up to 9 players).
*   **Full Game History**: Never lose track of a move. The app logs every score adjustment during the session.
*   **"No-Scroll" Responsive Layout**: The UI dynamically scales to fit perfectly on any device, from the smallest Android phones up to 12.9" iPads, without awkward scrolling.
*   **Custom Player Names**: Personalize your game by naming the meeples.
*   **Privacy First**: 100% local processing. No internet connection required, no accounts, and zero data collection.

## 🛠️ Technology Stack

This application is built with modern, high-performance mobile technologies:

*   **[React Native](https://reactnative.dev/)**: Core framework for cross-platform rendering.
*   **[Expo](https://expo.dev/)**: Development platform and build pipeline (EAS) for seamless iOS and Android deployment.
*   **[React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/)**: Powers the buttery-smooth layout transitions and temporary score popups.
*   **[Expo Image](https://docs.expo.dev/versions/latest/sdk/image/)**: Ensures instantaneous rendering and caching of the custom meeple assets.
*   **[Tailwind CSS](https://tailwindcss.com/)**: Utility-first styling configured for native view sizing and responsive design.

## 🚀 Running Locally

1. Ensure you have Node.js and npm installed.
2. Clone this repository.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the Expo development server:
   ```bash
   npx expo start
   ```
5. Scan the QR code with the **Expo Go** app on your physical device, or press `i` for the iOS Simulator / `a` for the Android Emulator.
